# منصة رصد الهلال (النسخة الشخصية) — دليل التشغيل

منصة سحابية ترصد ما يُنشر عن هيئة الهلال الأحمر السعودي على مدار الساعة **بدون Claude**، وتنبهك على جوالك.

## كيف تعمل (باختصار)
كل 30 دقيقة يقوم السيرفر بالآتي:
1. **يجمع** من: X، تيك توك، الأخبار، يوتيوب، قنوات تيليجرام، تقييمات تطبيقات الهيئة، ريديت، المنتديات، خرائط قوقل.
2. **يفرز** الواضح مجانًا بالقواعد (دروس الاستبعاد من دليل التصنيف).
3. **يصنّف** الباقي بالذكاء المجاني (Gemini، وبديله Groq، وبديلهما القواعد) حسب دليل التصنيف نفسه.
4. **يدمج** نفس القصة من أكثر من منصة في تنبيه واحد.
5. **ينبهك**: العاجل منفردًا بصوت صفارة، والباقي في رسالة مجمّعة. بدون أي تكرار.
6. **يحفظ** في قاعدة على السيرفر، ونسخة في جدول Google تفتحها من جوالك، ولوحة متابعة بهوية الهيئة.

ويرسل ملخصًا يوميًا 8 صباحًا، وتقريرًا كل أحد، وتقريرًا أول كل شهر.

## البدائل (لا نقطة تعطل واحدة)
| الجزء | الأساسي | البديل |
|---|---|---|
| التشغيل | سيرفر Oracle المجاني | GitHub Actions يستلم تلقائيًا إذا غاب السيرفر 75 دقيقة |
| X | حساب الرصد | الحساب الاحتياطي ← بحث الويب |
| تيك توك | حساب الرصد | بحث الويب |
| الأخبار | Google News | Bing News |
| يوتيوب | صفحة البحث (أو المفتاح) | بحث الويب |
| التصنيف | Gemini | Groq ← القواعد |
| التنبيهات | Pushover | تيليجرام ← البريد |
| البيانات | قاعدة السيرفر | جدول Google (يُحدَّث كل دورة) |
| المراقبة | Healthchecks.io | سطر «النظام شغّال» في الملخص اليومي |

أي تحويل لبديل تصلك عنه رسالة واحدة هادئة، ورسالة ثانية لما يرجع الأساسي.

## خطوات التشغيل (مرة واحدة)
1. **الجدول واللوحة (3 دقائق):** أنشئ جدول Google جديدًا ← الإضافات ← Apps Script ← الصق `apps_script/Code.gs` ← شغّل `setup` (وافق على الصلاحيات) ← انسخ قيمة `SHEET_SECRET` من السجل ← Deploy ← New deployment ← Web app (Execute as: Me، Who has access: Anyone) ← انسخ الرابط.
2. **مفتاح Gemini (دقيقة):** aistudio.google.com ← Get API key.
3. **Healthchecks.io (دقيقتان):** سجّل بقوقل ← Add Check (Period 30 دقيقة، Grace 15) ← انسخ رابط Ping. ويمكنك ربطه بـ Pushover من Integrations.
4. **GitHub:** مستودع خاص `srca-monitor` في حسابك وارفع ملفات هذا المجلد، ثم أضف المفاتيح في Settings ← Secrets ← Actions بنفس أسماء `.env.example`.
5. **سيرفر Oracle:** أنشئ VM (Ubuntu، الشكل المجاني Ampere A1) والصق `deploy/cloud-init.sh` بعد تعبئته في «Initialization script». يركّب كل شيء وحده.
6. **اختياري:** حساب تيك توك للرصد (الكوكيز)، مفتاح Brave Search المجاني (لتفعيل المنتديات وبديل X وتيك توك)، مفتاح Groq المجاني.

## الأوامر (على السيرفر)
- فحص فوري: `sudo systemctl start srca-run.service`
- اختبار كل الأجزاء مع إشعار تجربة: `sudo -u srca /opt/srca-monitor/.venv/bin/python -m srca.main test`
- السجل: `journalctl -u srca-run.service -n 100`
- الجداول الزمنية: `systemctl list-timers 'srca-*'`

## إذا صار شيء
| الرسالة | المعنى | الحل |
|---|---|---|
| «مصدر X متعطل والرصد مستمر بالبديل» | انتهت جلسة حساب الرصد | سجّل دخول حساب الرصد من المتصفح وحدّث `X_AUTH_TOKEN` |
| «التصنيف الذكي غير متاح» | مفتاح Gemini أو حصته | يعمل بالقواعد تلقائيًا؛ أضف مفتاح Groq أو انتظر تجدد الحصة |
| «السيرفر الأساسي لا يستجيب» | توقف السيرفر | الاحتياطي شغّال؛ أعد تشغيل السيرفر من لوحة Oracle |
| «الفحص تعطل 3 مرات» | خطأ غير متوقع | راجع السجل |
| رسالة Healthchecks بالبريد | لم يصل نبض 45 دقيقة | السيرفر والاحتياطي متوقفان، راجع Oracle |

## مبادئ ثابتة
- **رصد فقط:** لا نشر ولا رد ولا تفاعل ولا تواصل مع أحد.
- **لا تنبيه متكرر:** أقصى أولوية 1 بصفارة، ولا أولوية 2 أبدًا.
- **الخصوصية:** الملخصات لا تنسخ التفاصيل الطبية الحساسة.
- **المفاتيح:** في `.env` على السيرفر وفي خزنة GitHub فقط، ولا مفاتيح داخل الكود.
